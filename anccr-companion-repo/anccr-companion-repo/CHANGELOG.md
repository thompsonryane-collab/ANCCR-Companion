# Changelog

## 0.5.0 — 2026-10-29

- Tab bar removed; the hub is the whole app.
- Learn the hub is a tile (ACR-16), first in the grid.
- Preset stakeholder questions moved into the ANCCR Analyst tile as its Ask tab.
- "New" badges removed; ACR codes removed from under tiles.
- Strategy tile (ACR-15): summary, meeting, gaps, plan, actions, mind map.
  - Mind map with tap-to-expand nodes, expand/collapse all, sticky controls, collapsed on open.
  - Priority matrix dots toggle on and off.
  - Actions, risks and open questions are collapsible sections.
  - Scroll-to-top caret in every sheet.
- Data pills open sample tables with schema and data views (19 tables).
- Sample Dataset tile (ACR-14): derivation, sources with live links, formulas, planted errors.
